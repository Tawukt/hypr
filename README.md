# hypr

## Colors file

As i am using `pywall`, create a first symlink:
```sh
ln -s $HOME/.config/hypr/colors-hyprland.template $HOME/.config/wal/templates/colors-hyprland.lua
```

Then create a second symlink:
```sh
ln -s $HOME/.cache/wal/colors-hyprland.lua $HOME/.config/hypr/colors-hyprland.lua
```
